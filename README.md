# ゲーム型授業シリーズ

児童福祉施設の小4〜6女子クラス向け「画面で体験するゲーム型授業」。全57作（理科21・社会36）。

各作品は外部依存なしの単一HTMLファイルで、ブラウザで開くだけで動作する。

## 使い方

`index.html` が全作品の一覧ページ（教科タブ・分野フィルタ・学年フィルタ・キーワード検索・じゅんばん表示・進捗と称号・「次はこれ！」おすすめ・なまえプロフィール切り替えを搭載）。ここから各作品にアクセスする。

- じゅぎょう画面：`<slug>.html`（例: `kururu.html`）
- A4記録シート（子ども用1ページ＋先生用進行メモ1ページ）：`<slug>-sheet.html`（例: `kururu-sheet.html`）

タブレット等からは公開URL https://shimimasa.github.io/elementgirl-lesson/ でもアクセスできる（あいことばによる簡易ゲートあり）。

## 全授業共通スクリプト

すべてのページ（一覧・じゅぎょう画面）が以下を読み込む：

- `auth.js` — あいことばゲート
- `orientation-guard.js` — スマホ・タブレット縦持ち時のよこむき案内（じゅぎょう画面のみ）
- `profile.js` — なまえプロフィール（端末を共有しても子どもごとに進捗を分けるための仕組み）
- `progress.js` — バッジ単位のクリア進捗をlocalStorageへ記録（じゅぎょう画面のみ）
- `mascots.js` — 各作品のキャラクターSVGを一覧ページのカード用に集約したもの
